TD Tour Traccar – Android

Step 1: install Traccar Client. Step 2: tap Configure Traccar.

1. Download Traccar Client

Google Play

Search for Traccar Client, or use the button below.

Open Google Play

2. Configure Traccar

Configure Traccar

3. After configuration

First select Change settings in Traccar Client to edit or check the Device identifier and Server URL.

  1. Open Traccar Client and select Change settings.
  2. Set Device identifier to Tour/Rally number followed by surname, for example 87 Smith.
  3. Check:
    • Server URL = TD Tour relay
    • Location accuracy = High
    • Distance = 500 m
    • Stationary heartbeat = 60 s (1 minute)
  4. Under Advanced settings, the configuration sets:
    • Offline buffering = Off
    • Wake lock = Off
    • Stop detection = Off
    Leave Use system location at the setting selected by Traccar for the device.
  5. On your Android phone, open Settings → Apps → Traccar Client → Battery and select Unrestricted. Verify that it shows Unrestricted even if Traccar already prompted for battery permission.
  6. Turn on Continuous tracking at the start of the Tour day.
  7. Turn off Continuous tracking at the end of the Tour day.

The Configure Traccar button applies the Tour tracking settings automatically. Enter the Device identifier as shown above, then start Continuous tracking on the Tour day.

TD Tour Traccar – iPhone / iOS

Step 1: install Traccar Client. Step 2: return to this page and enter the settings below.

1. Download Traccar Client

App Store

Search for Traccar Client, or use the button below.

Open App Store

2. Copy the Server URL

Loading Tour Server URL…

3. Traccar settings

First open Traccar Client and select Change settings to enter or edit the Device identifier and Server URL.

  1. Device identifier = Tour/Rally number followed by surname, for example 87 Smith.
  2. Server URL = paste the copied TD Tour relay URL.
  3. Location accuracy = High.
  4. Distance = 500 m.
  5. Stationary heartbeat = 60 s (1 minute).
  6. Select Advanced settings.
  7. Offline buffering = Off.
  8. Stop detection = Off.
  9. Turn on Continuous tracking at the start of the Tour day.
  10. Turn it off at the end of the Tour day.
iPhone / iOS: setup is manual. Copy the Server URL above, then enter the settings exactly as listed.
